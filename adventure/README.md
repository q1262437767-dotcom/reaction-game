# 遗迹小队

原创俯视角动作小游戏。静态 HTML、CSS、JavaScript，无构建步骤。

## 节奏战斗与招架试炼

默认装备为旅人短刃，J / 鼠标左键近身攻击，K / 鼠标右键按住防守。在斩击落下前按下防守，可以精准招架；成功化解后再次攻击，可打出反击。防守普通攻击也有代价，连续硬挡会被破防。

精英与 Boss 的关键攻击有明确蓄势、地面范围和声音预告。连续斩击需要分别接住每一拍；突刺时迎向敌人闪进可截住攻势，横扫和大范围震地则要抓准落点闪避。成功时有金属碰撞、短暂顿帧、失衡与反击窗口。震屏与闪光保持短促，系统开启减少动态效果时关闭这些效果。

首页“招架试炼”可直接单人挑战一名持刃守卫。首次进入会暂停并显示一次说明，准备好后再迎战；之后不重复显示，可随时从问号或暂停菜单查看手册。试炼结束只提供重试和返回营地，不增加探险次数、奖励、图鉴、徽章或云存档成长。

手机端新增盾牌按钮用于防守与招架；原手枪和已解锁的散射枪仍可在出发前选择。声音可随时静音，无音频设备也能依靠动作与范围提示游玩。

## 随机探索（默认主模式）

每次出发生成 12 间互相连通的遗迹房间，带分岔和回路。可以自由进出房间，无须清光敌人。再次回来时，敌人的血量、死亡、遗物和补给状态都保留；搬着的道具会安全放回离开的房间。

- 右上角小地图开局仅显示入口、相邻房间和 Boss 的位置；进入新房间后逐步揭开迷雾，未探索的中间路线不会预先显示。
- 击杀本局约 60% 的普通守卫及精英后，Boss 苏醒。提前进入 Boss 房可以自由离开，不会提前生成 Boss 或结束探险。
- 3 名精英分散在随机房间里，击败后原地掉落穿透棱镜、疾风羽饰或生命苔石。清理普通房间不再奖励遗物；遗物为全队共享，仅本局生效。
- 击败 Boss 后带回 40 星屑，险境额外 20。每次重新出发都会生成新地图。现有账号存档、星屑和解锁仍可使用。
- 教学只在这台设备首次进入的起始房显示，可直接关闭。随时可从暂停菜单或右上角问号查看完整手册。

## 故事任务

完成三种任务，逐盏修复营地的三盏灯：

1. **熄灭炉心**：通过战斗与水闸机关，击败炉心守卫。完成后开启物资回收。
2. **物资回收**：搜索三个战斗房里的补给箱，带齐物资后在撤离点按 E 返回。完成后开启信标守夜。
3. **信标守夜**：在中央启动信标，守住三波敌人，再按 E 撤离。

三盏灯全部点亮后开放险境难度。营地还有无伤、隐藏室、遗物收集及险境通关徽章。

清理房间或完成守卫波次后，场景会出现遗物供全队二选一。本局可获得穿透棱镜、疾风羽饰、生命苔石，不重复叠加，返回营地后重置。

- WASD / 方向键移动，鼠标瞄准，J / 左键攻击，K / 右键防守。
- 空格闪避，E 搬起/放下箱子、投掷炸药桶、浇水、补水、救援。
- 手机使用屏幕摇杆与按钮，攻击时自动瞄准最近敌人。
- 清理房间后穿过东侧光门继续；机关房用水桶灭火，搬木箱压住开关可探索隐藏室。
- 任务分别带回 40 / 30 / 35 星屑，险境额外 20，隐藏室额外 12。30 星屑解锁另一种起始武器。营地数据保存在当前浏览器 localStorage；旧版星屑、武器和通关数据会自动迁移。

## 联机

打开同一个网页，房主点“邀请朋友 → 创建双人房间”，将 8 位房间码发给朋友。朋友加入后，房主点“一起出发”。游戏数据通过 WebRTC 传输，房主负责模拟。

使用随仓库附带的 MIT 许可 PeerJS 1.5.5 和其默认公共信令服务。当前原型未配置自建 TURN 中继，因此部分 NAT、公司网络或无法访问公共信令服务的网络可能无法联机。连接失败可单人游玩。角色、场景和音效均由本项目代码生成。

联机协议为第 4 版，双方都需刷新到最新页面。模式、任务和难度由房主选择；两人共享同一张随机地图和当前房间，一人通过门时全队同行。客人即使尚未解锁故事任务，也能随房主出发并正常记录结果。

## 邮箱账号与云存档

账号接入代码位于 `cloud.js` / `account.js`，公开配置为 `cloud-config.js`。数据库初始化及邮件发送配置见 `backend/SETUP.md`。填写有效项目配置并完成数据库与 SMTP 配置后，启用邮箱密码登录、邮箱验证注册和云存档；空配置保持游客本地模式。

- 游客存档和账号存档分开，首次登录新账号可选择导入游客进度。
- 默认使用邮箱和密码登录；注册时设置密码并输入邮件验证码确认邮箱。密码不进入营地存档、导出文件或本机存档缓存。
- 原来的验证码账号可以在登录后的账号面板设置密码，继续使用同一份进度。忘记密码时先验证邮箱，再设置新密码；验证码登录也保留为备用入口。
- 结算和装备解锁会先保存本机备份，再自动同步；网络中断会保留待上传进度。
- 多设备进度冲突时由玩家明确选择，不自动叠加货币或覆盖。
- 可导出/导入 JSON 备份；导入须确认，备份文件不包含邮箱或会话凭据。
- 当前是客户端游戏的进度备份，不能等同于服务器验证奖励的反作弊经济系统。

## 本地运行与测试

在本目录启动任意静态 HTTP 服务（例如 Python `python -m http.server 8000`），然后打开 `http://localhost:8000`。发布时将目录放到 GitHub Pages 的 `adventure/` 下即可。

浏览器切后台会暂停，需回到页面继续。队友断线时房主可转为单人继续；房主断线时队友返回营地重新开始。
