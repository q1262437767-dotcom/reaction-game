# 遗迹小队

原创俯视角动作小游戏。静态 HTML、CSS、JavaScript，无构建步骤。

## 探险目标

完成三种任务，逐盏修复营地的三盏灯：

1. **熄灭炉心**：通过战斗与水闸机关，击败炉心守卫。完成后开启物资回收。
2. **物资回收**：搜索三个战斗房里的补给箱，带齐物资后在撤离点按 E 返回。完成后开启信标守夜。
3. **信标守夜**：在中央启动信标，守住三波敌人，再按 E 撤离。

三盏灯全部点亮后开放险境难度。营地还有无伤、隐藏室、遗物收集及险境通关徽章。

清理房间或完成守卫波次后，场景会出现遗物供全队二选一。本局可获得穿透棱镜、疾风羽饰、生命苔石，不重复叠加，返回营地后重置。

- WASD / 方向键移动，鼠标瞄准，按住左键射击。
- 空格闪避，E 搬起/放下箱子、投掷炸药桶、浇水、补水、救援。
- 手机使用屏幕摇杆与按钮，射击时自动瞄准最近敌人。
- 清理房间后穿过东侧光门继续；机关房用水桶灭火，搬木箱压住开关可探索隐藏室。
- 任务分别带回 40 / 30 / 35 星屑，险境额外 20，隐藏室额外 12。30 星屑解锁另一种起始武器。营地数据保存在当前浏览器 localStorage；旧版星屑、武器和通关数据会自动迁移。

## 联机

打开同一个网页，房主点“邀请朋友 → 创建双人房间”，将 8 位房间码发给朋友。朋友加入后，房主点“一起出发”。游戏数据通过 WebRTC 传输，房主负责模拟。

使用随仓库附带的 MIT 许可 PeerJS 1.5.5 和其默认公共信令服务。当前原型未配置自建 TURN 中继，因此部分 NAT、公司网络或无法访问公共信令服务的网络可能无法联机。连接失败可单人游玩。角色、场景和音效均由本项目代码生成。

联机协议为第 2 版，双方都需刷新到最新页面。任务由房主选择；客人即使尚未解锁该任务，也能随房主出发并正常记录结果。

## 本地运行

在本目录启动任意静态 HTTP 服务（例如 Python `python -m http.server 8000`），然后打开 `http://localhost:8000`。发布时将目录放到 GitHub Pages 的 `adventure/` 下即可。

浏览器切后台会暂停，需回到页面继续。队友断线时房主可转为单人继续；房主断线时队友返回营地重新开始。
