# 遗迹小队

原创俯视角动作小游戏。静态 HTML、CSS、JavaScript，无构建步骤。

## 武器配合与环境战斗

- 短刃命中会积累敌人的失衡值，打满后使其短暂失衡并暴露弱点。精准化解攻击与主动反击也会创造短暂弱点。
- 弱点持续 1.6 秒，手枪第一次实际命中会额外造成 2 点伤害，并消耗这次弱点。可以继续近战反击，或按 Q 切枪追击；射出远程攻击会消耗正在等待的反击机会。
- 散射枪在 190 像素内命中会击退敌人；同一轮散射对同一敌人只推一次，精英和 Boss 的击退较小。
- 巨兽冲锋会撞碎木箱、引爆炸药桶，也能撞伤并推开其他怪物；撞上墙壁或掩体后仍有失衡机会。敌人火球撞到炸药桶时也会引爆，可以利用这些反应设伏。
- 普通命中、弱点追击、失衡、近战完整格挡、远程半效格挡及武器损坏使用不同的短暂声音和视觉反馈；伤害数字显示实际数值。反馈会合并连续弹丸，避免同一次散射挤满画面。

这轮升级沿用既有按键与 0.38 秒招架窗口，近战与远程各带一把；不会更改账号存档格式。

## 固定操作与双武器

每名玩家只携带两个武器槽：一把近战短刃和一把远程武器。出发时选择手枪，或用已解锁的散射枪替换手枪；默认先手持短刃。

| 操作 | 键盘 / 鼠标 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左摇杆 |
| 攻击 | J / 鼠标左键 | 攻击按钮 |
| 格挡并静步 | 按住 K / 鼠标右键 | 按住盾牌按钮 |
| 切换近战与远程 | Q | 切换按钮 |
| 闪避 | 空格 | 闪避按钮 |
| 互动 | E | 互动按钮 |

- K 在两种武器下都会减缓移动，变为静步；搬运时也可轻步移动。连斩等正面可格挡攻击依然能精准招架，窗口为 0.38 秒；突刺、横扫、震地等关键攻击仍需按原规则闪避。
- 手持近战时，成功格挡抵消该次可格挡攻击的伤害；连续硬挡仍会承压、破防。
- 手持远程时，成功格挡仅减少 50% 伤害；每次实际挡到攻击有 10% 概率损坏远程武器。空按、静步或未接触攻击不会判定损坏。
- 远程损坏后本局失效，自动切回近战，槽位保留损坏提示；重新出发时恢复，不扣除星屑，也不删除账号里的武器解锁。
- Q 每次按下只切换一次，短暂切换冷却与攻击冷却会保留；切换不会刷新精准招架窗口。

## 苔火猎场试玩

营地模式菜单选择“猎场”，可单人或通过已有双人房间出发。六间遗迹组成一条环路，目标是在其中追踪并击败“逐迹巨兽”。无需清理所有小怪，房门始终开放。

- 巨兽会跨房间巡逻，并向听见的声音靠近。普通脚步、攻击与闪避、炸药桶爆炸的传播范围不同；按住 K / 防守按钮慢走时保持安静。
- 门口的足迹、邻房传来的沉重脚步，以及上次目击的标记可以帮助追踪。小地图不会直接显示尚未目击的巨兽当前位置；接近当前房间前有短暂的门口警示。
- 可以搬动木箱和炸药桶布置战场，用攻击或爆炸引它过来。撤到别处后，巨兽受过的伤仍保留；玩家能选择追击、绕路或等待伏击。
- 巨兽按固定次序使用连斩、冲撞和震地：连斩可以招架反击，冲撞撞到障碍会失衡，震地可抓准时机闪避。精准招架仍为 0.38 秒。
- 击败巨兽后直接完成狩猎，奖励 32 星屑。沿用已有本地与账号云存档，不点亮故事营灯。模式目前固定普通难度。

## 接力夺宝试玩

营地模式菜单选择“接力夺宝”，可单人或使用已有双人房间出发。三间连通房间：从苔灯撤离站出发，穿过断桥庭院，进入炉芯密库，将唯一一枚炉芯带回入口撤离站。房门始终开放，无须清光敌人。

- 靠近落地炉芯按 E 拾取，搬运时移动稍慢；瞄准后再次按 E 投出。失手的炉芯可以重新拾取，撞墙后会落地，不会损坏或消失。
- 空手按住 K / 防守按钮可接住飞来的炉芯；在到达前按下防守，使用原有 0.38 秒精准窗口接住，可获得 3 秒移动强化。单人不需要完成接力也能撤离。
- 搬运者受伤时炉芯掉落，队友可以接手；举着炉芯穿门会一同带到下一房，放在地上的炉芯则留在原房间。敌人与炉芯碰撞会产生击退和短暂失衡。
- 首次拿起炉芯会惊动回程巡逻队；原路房门依然开放，可以掩护接力或直接突围。举着炉芯时闪避距离较短，原有无敌与精准闪避窗口保留。
- 回到起点，带着炉芯靠近撤离台按 E 完成。结算记录投掷、接住与精准接力次数，成功带回 24 星屑，沿用现有本地与账号云存档；不点亮故事任务的灯，不解锁后续故事任务。

此模式为三个房间的玩法验证，固定普通难度。随机遗迹仍为默认模式。

## 苔火遗迹内容版

一片 12 房随机遗迹，保留自由穿行、迷雾探索和击杀唤醒 Boss 的规则。

- 三种精英：守刃者的连斩与突刺、冲撞巨兽的锁向冲锋与撞墙失衡、引火祭司的可反射火球。各自有明确的蓄力动作和落点，沿用 0.38 秒精准招架窗口。
- 两种可选事件：开启水闸会灭掉火路、打开内部近道并惊动巡逻精英；启动升降台后击退增援，可领取一次全队回血与一层护盾。可离开后回来，机关与奖励状态保留，觉醒门槛不因支线提高。
- 六件遗物：穿透棱镜、疾风羽饰、生命苔石、鸣震核心、回刃纹章、留影灯芯。新增反击冲击、连续招架后的范围斩和精准闪避残影诱敌。精英掉落两件供全队选一件，其他房间不直接奖励遗物。
- 随机模式 Boss 半血后炉火觉醒，内侧石柱崩塌，并加入大范围震地；外墙与房间出口保留。
- 营地新增六件遗物图鉴，发现记录在结算后随既有账号云存档同步；旧版星屑、武器、任务和徽章兼容。部署升级使用 backend/upgrade-six-relics.sql，只扩充允许保存的遗物记录，不更改已有存档行。

这是一轮内容扩充。金币、累计星屑里程碑和第二个地区属于后续规划，当前仍沿用星屑解锁散射枪的成长规则。

## 节奏战斗与招架试炼

默认装备为旅人短刃，J / 鼠标左键近身攻击，K / 鼠标右键按住防守。看到两圈快合拢或听到清脆提示时按下防守，可以精准招架；防守会自动面向来招，无需额外对准鼠标。成功化解后再次攻击，可打出反击。防守普通攻击也有代价，连续硬挡会被破防。

精英与 Boss 的关键攻击有明确蓄势、地面范围和声音预告。连续斩击需要分别接住每一拍；突刺时迎向敌人闪进可截住攻势，横扫和大范围震地则要抓准落点闪避。成功时有金属碰撞、火花、失衡与反击窗口。震屏与闪光保持短促，系统开启减少动态效果时关闭这些效果。

首页“招架试炼”可直接单人挑战一名持刃守卫，先练连斩，熟悉后再加入突刺和横扫。首次进入会暂停并显示一次说明，准备好后再迎战；之后不重复显示，可随时从问号或暂停菜单查看手册。试炼结束显示本轮成功招架次数，可重试或返回营地，不增加探险次数、奖励、图鉴、徽章或云存档成长。

手机端新增盾牌按钮用于防守与招架；原手枪和已解锁的散射枪仍可在出发前选择。声音可随时静音，无音频设备也能依靠动作与范围提示游玩。

## 随机探索（默认主模式）

每次出发生成 12 间互相连通的遗迹房间，带分岔和回路。可以自由进出房间，无须清光敌人。再次回来时，敌人的血量、死亡、遗物和补给状态都保留；搬着的道具会安全放回离开的房间。

- 右上角小地图开局仅显示入口、相邻房间和 Boss 的位置；进入新房间后逐步揭开迷雾，未探索的中间路线不会预先显示。
- 击杀本局约 60% 的普通守卫及精英后，Boss 苏醒。提前进入 Boss 房可以自由离开，不会提前生成 Boss 或结束探险。
- 三种精英分散在随机房间里，击败后在附近掉落二选一遗物。清理普通房间不奖励遗物；六种遗物为全队共享，仅本局生效。
- 击败 Boss 后带回 40 星屑，险境额外 20。每次重新出发都会生成新地图。现有账号存档、星屑和解锁仍可使用。
- 教学只在这台设备首次进入的起始房显示，可直接关闭。随时可从暂停菜单或右上角问号查看完整手册。

## 故事任务

完成三种任务，逐盏修复营地的三盏灯：

1. **熄灭炉心**：通过战斗与水闸机关，击败炉心守卫。完成后开启物资回收。
2. **物资回收**：搜索三个战斗房里的补给箱，带齐物资后在撤离点按 E 返回。完成后开启信标守夜。
3. **信标守夜**：在中央启动信标，守住三波敌人，再按 E 撤离。

三盏灯全部点亮后开放险境难度。营地还有无伤、隐藏室、遗物收集及险境通关徽章。

清理房间或完成守卫波次后，场景会出现遗物供全队二选一。本局可获得穿透棱镜、疾风羽饰、生命苔石，不重复叠加，返回营地后重置。

- WASD / 方向键移动，鼠标瞄准，J / 左键攻击，K / 右键防守。
- 空格闪避，E 搬起/放下箱子、投掷炸药桶、浇水、补水、救援。
- 手机使用屏幕摇杆与按钮，攻击时自动瞄准最近敌人。
- 清理房间后穿过东侧光门继续；机关房用水桶灭火，搬木箱压住开关可探索隐藏室。
- 任务分别带回 40 / 30 / 35 星屑，险境额外 20，隐藏室额外 12。30 星屑解锁另一种起始武器。营地数据保存在当前浏览器 localStorage；旧版星屑、武器和通关数据会自动迁移。

## 联机

打开同一个网页，房主点“邀请朋友 → 创建双人房间”，将 8 位房间码发给朋友。朋友加入后，房主点“一起出发”。游戏数据通过 WebRTC 传输，房主负责模拟。

使用随仓库附带的 MIT 许可 PeerJS 1.5.5 和其默认公共信令服务。当前原型未配置自建 TURN 中继，因此部分 NAT、公司网络或无法访问公共信令服务的网络可能无法联机。连接失败可单人游玩。角色、场景和音效均由本项目代码生成。

联机协议为第 10 版，双方都需刷新到最新页面。模式、任务和难度由房主选择；两人共享同一张地图和当前房间，一人通过门时全队同行。客人即使尚未解锁故事任务，也能随房主出发并正常记录结果。

猎场与接力夺宝首次进入时，会等待双方看完各自的一次性说明，再开始模拟；搭档断线后，房主转为单人继续时会解除等待。

## 邮箱账号与云存档

账号接入代码位于 `cloud.js` / `account.js`，公开配置为 `cloud-config.js`。数据库初始化及邮件发送配置见 `backend/SETUP.md`。填写有效项目配置并完成数据库与 SMTP 配置后，启用邮箱密码登录、邮箱验证注册和云存档；空配置保持游客本地模式。

- 游客存档和账号存档分开，首次登录新账号可选择导入游客进度。
- 默认使用邮箱和密码登录；注册时设置密码并输入邮件验证码确认邮箱。密码不进入营地存档、导出文件或本机存档缓存。
- 原来的验证码账号可以在登录后的账号面板设置密码，继续使用同一份进度。忘记密码时先验证邮箱，再设置新密码；验证码登录也保留为备用入口。
- 结算和装备解锁会先保存本机备份，再自动同步；网络中断会保留待上传进度。
- 多设备进度冲突时由玩家明确选择，不自动叠加货币或覆盖。
- 可导出/导入 JSON 备份；导入须确认，备份文件不包含邮箱或会话凭据。
- 当前是客户端游戏的进度备份，不能等同于服务器验证奖励的反作弊经济系统。

## 本地运行与测试

在本目录启动任意静态 HTTP 服务（例如 Python `python -m http.server 8000`），然后打开 `http://localhost:8000`。发布时将目录放到 GitHub Pages 的 `adventure/` 下即可。

浏览器切后台会暂停，需回到页面继续。队友断线时房主可转为单人继续；房主断线时队友返回营地重新开始。
