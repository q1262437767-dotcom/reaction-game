# 放置修仙

打开网页就能玩的单人修仙挂机游戏。

**在线游玩：<https://q1262437767-dotcom.github.io/reaction-game/>**

从炼气一层开始，打坐积累修为，逐步突破至筑基、金丹、元婴与化神。采药与灵植提供丹药材料，采矿与炼器打造法器，历练获取灵石和秘境灵材。

## 怎么玩

1. 在“修炼”页点击“打坐吐纳”。约一分钟后，点击境界卡片里的“突破境界”。
2. 技艺升级会解锁更高效的修炼方法和采集地点。
3. 采集灵草与灵露，在“炼丹”页制作回血丹。
4. 采集青铜矿和灵草，在“炼器”页熔炼青铜锭，再炼制青铜剑与法袍。
5. 在“储物袋”里穿戴法器，去“历练”挑战妖兽。气血偏低时自动消耗丹药。
6. 出售多余物品赚灵石，在仙坊购买永久工具升级，或为后续突破准备灵石。

每次进行一项活动。采集与修炼持续进行，制作在材料不足时停止，历练被击退后停止并恢复气血。突破必定成功，会消耗所需修为、灵石与材料。

## 存档与离线

- 每 5 秒自动保存到当前浏览器。
- 关闭网页后，再次打开会结算上次活动，最多 8 小时。制作仍需消耗真实材料，历练仍需消耗丹药。
- 点击右上角“存档”，可导出或导入 JSON 备份。换设备或清理浏览器数据前请先导出。
- 同一浏览器的多个标签页只有一个负责结算，另一个可以点击“在这里继续修行”接管。
- 本作是本地存档的单人游戏，存档不会自动同步到账号或其他设备。

## 文件与发布

`index.html`、`style.css`、`game.js`、`app.js` 放在同一目录即可运行，无须构建或后端。GitHub Pages 从 `main` 分支根目录发布。

更改样式或脚本时，更新 `index.html` 中的 `?v=` 版本号，方便浏览器加载新文件。

玩法与修仙题材为本作原创实现，未使用其他游戏的图片、代码或数据。
